# inkroam

E-ink дашборд, который работает там, куда его привезли.

Кадр рисует само устройство. Нет сервера с браузером, нет зашитой в прошивку
сети, нет привязки к конкретному дому. Wi-Fi и источники данных настраиваются
с телефона через страницу, которую устройство отдаёт само.

Железо: TRMNL 7.5" DIY Kit (XIAO ESP32-S3 + Waveshare 7.5" V2, 800×480, 1 бит).

## Зачем ещё один

Предшественник — [`trmnl-ink`](../trmnl-ink) — стоит дома и показывает курсы,
лимиты AI-подписок, воздух в кабинете и почту. Он рисует кадр на сервере
headless-браузером и тянет готовый PNG. Дома это работает отлично.

В поездке — нет. Сервер остался дома, сеть в гостинице другая, а чтобы
поменять SSID, нужен ноутбук с кабелем. `inkroam` переделан ровно под это:
устройство самодостаточно, а всё, что зависит от места, настраивается на
месте.

Подробно, с ценой каждого решения — [docs/decisions.md](docs/decisions.md).

## Как это работает

```
  ┌─────────────┐   HTTP/JSON    ┌──────────────────────────────┐
  │  коннектор  │ ─────────────► │         устройство           │
  │  (любой)    │   значения     │                              │
  └─────────────┘                │  разбор → слоты → раскладка  │
                                 │            ↓                 │
  ┌─────────────┐                │      рисование примитивами   │
  │ Home Assist.│ ─────────────► │            ↓                 │
  │    REST     │                │        e-ink 800×480         │
  └─────────────┘                └──────────────────────────────┘
```

**Коннектор** — источник данных. Отдаёт JSON с именованными значениями.
Встроенные: Home Assistant (REST), произвольный HTTP/JSON, публичные API без
ключа. Что откуда брать — настраивается через веб, не перепрошивкой.

**Слот** — именованная ячейка дизайна: `btc`, `usd_rub`, `co2`,
`limit.claude`. Коннектор заполняет слоты, раскладка рисует те блоки, чьи
слоты заполнены. Нет данных — нет блока, кадр не ломается.

**Рендер** — на устройстве: растровый шрифт Terminus, линии, прямоугольники,
спарклайны. Тот же 1-битный язык, что у предшественника, только считается на
ESP32, а не в Chromium.

## Сеть

При старте устройство пытается подключиться к сохранённым сетям. Не вышло —
поднимает свою точку доступа `inkroam-setup` и держит страницу настройки: там
можно выбрать сеть из списка, ввести пароль, задать адреса коннекторов и
ключи. Сохранённые сети переживают перезагрузку и отключение питания.

Bluetooth не используется намеренно — [почему](docs/decisions.md#5).
